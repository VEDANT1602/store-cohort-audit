# Data card

Four hundred original store-period-day count rows cover 20 fictional stores over ten days before and after. Volume shifts toward lower-baseline stores while each latent completion probability increases by 0.03. One sparse store fails the minimum of 50 accepted orders per period. A fixed equal-store reference mix is supplied independently of observed outcomes. Rates are completed orders divided by accepted orders. Standardization answers a fixed-store-mix question rather than the order-weighted aggregate. Bootstrap resamples whole store pairs and is descriptive over 19 supported stores. No intervention or causal field result is asserted.

All fixtures were generated specifically for this independent project. No upstream dataset, weights, media or result numbers were imported.
